# Jarvis_HA
Description: Home assistant blank slate using an old laptop

Goal: Learn and have fun

Success Criteria:

Materials: 
USB Drive > 8GB
Old Laptop (zBook i5) I wiped mine completely, Windows and all
Ethernet Cable (optional but highly recommended)

Steps I Took:
1. Download Ubuntu ISO Desktop and any Etching software (I used belena, and this is not on the old laptop, but the current one)
2. Etch Ubuntu ISO Desktop into the USB Drive (current laptop)
3. Insert Drive into Old Laptop and power on, then click Esc
4. Turn off Secure Boot, save changes and Power + Esc again
5. Select Try or Install Ubuntu
6. Connect old laptop to your wifi network
7. Open Firefox and navigate to home-assistant.io
8. Download the latest disk image (img.xz)
9. Open Disks, select the SSD drive, click the vertical elipse and then select Restore Disk Image
10. Go to downloads and select the disk image you just downloaded
11. Start Recording
12. Once complete, power off old laptop and unplug USB, wait a few minutes before powering back on


Problems + Solutions:
P: Apartment wifi restrictions mean that wireless to wireless communication is not allowed
S: By connecting both devices with an ethernet cable, I am able to bypass this restriction to complete onboarding config
